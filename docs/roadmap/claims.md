# Claims

A claim says "this plan is mine now", so that no two agents start the same plan from three separate clones. It works without any server except the shared git remote.

## The rule

- **The claim is the tag `claim/<NNN>` on `origin`.** It is created with `git tag claim/<NNN> && git push origin claim/<NNN>` right after the claim commit (README step d). Git refuses to push a tag that already exists on the remote, so the first push wins. An agent whose push is refused deletes its branch and picks again.
- An agent claims only the tasks of its own lane (roadmap §4.2), or a task given to it in [`checkpoints.md`](checkpoints.md) "Reassignments", and only when every WAIT checkpoint exists.
- An agent holds **one** claim per worker: at most as many open claims as its machine's sub-worker limit (roadmap §2).
- Only Agent 1 deletes a claim tag: after the merge (§7.2 step 9) or when it reassigns a plan (§8). An agent that gives up a plan says so in its plan Log and its next handover or status report. Agent 1 then deletes the tag.
- To see all open claims: `git ls-remote --tags origin 'refs/tags/claim/*'`. To see handovers waiting for a merge: `git ls-remote --tags origin 'refs/tags/ready/*'`.

Without a shared remote (bundle fallback, README) there are no claim tags. Each agent takes only its own lane, in order.
