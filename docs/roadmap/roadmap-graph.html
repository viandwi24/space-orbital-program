Checkpoint yang membuka paling banyak kerja

CheckpointOlehMembuka

Setiap plan yang di-merge memberi satu tag cp/f<fase>-<NNN>-<slug>. Daftar lengkap ada di checkpoints.md.

Jalur kritis

Rantai comms, ±17 jam walau mesinnya tak terbatas. Saingan terdekat: karier 077 → 078 → 087 → 091 → 094 → 096 → 097 → 126 (±16,5 j). Yang paling menentukan sebenarnya lane Agent 2: kalau tertinggal, pindahkan 131 lalu 065 ke Agent 3.

Protokol tag git

  • claim/NNN sebelum mulai plan
  • ready/NNN saat siap diserahkan ke Lead
  • bounce/NNN jika Lead mengembalikan
  • cp/… hanya dibuat Lead setelah merge ke main

Kickoff: dari komputer ini ke dua dev lain

  1. Push dari terminal kamu sendiri (shell Claude tidak punya kunci SSH kamu). Ada 8 commit dokumen yang belum di-push. 
    git push origin main
git tag cp/f0-kickoff
git push origin cp/f0-kickoff
  2. Beri akses push ke repo viandwi24/space-orbital-program untuk akun GitHub di mesin M2 dan Linux.
  3. Di M2 dan Linux: clone, pasang dependensi, lalu jalankan baseline dan catat durasi serta memori puncaknya. 
    git clone git@github.com:viandwi24/space-orbital-program.git
cd space-orbital-program && bun install
bun test && bun run typecheck && bun run docs:check
  4. Tempel prompt agen di sesi Claude Code masing-masing mesin (tombol Salin di kartu agen di atas). Untuk melanjutkan sesi berikutnya: Lanjutkan pekerjaanmu sesuai docs/roadmap/README.md. Kamu adalah Agent 2.
