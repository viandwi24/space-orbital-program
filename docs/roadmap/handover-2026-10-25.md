## How measurements must be taken (lessons from 2026-10-24/25)

- **Headed Chromium only.** Headless is paced at 60 Hz, which put a 16.7 ms floor under every number in the first version of 07-look-costs. `measure-120hz.ts` is headed. `measure-looks.ts` and `probe-textures.ts` were fixed to run headed.
- **One measurement at a time.** Write your name into `/tmp/orbital-measuring`, check that it is absent before starting, and remove it only if it still holds your name. Never start a run while it holds someone else's name.
- **A quiet machine.** Load must be ≤ 3, the M5 plugged in, and no build or test running. Use interleaved A/B runs: the baseline build and the change served together and alternated within the same minutes. Absolute numbers drift ±4 ms between runs.
- **Report the mean and the share of frames over the interval,** not only p95. p95 snaps to vsync steps (8.3, 16.7, 33.4 ms).

## Rules that must not regress
