## Scaffold commands (copy-paste)

```sh
bun init --yes                                   # new library package; then move index.ts → src/
bunx sv@1.1.1 create <dir> --template minimal --types ts --add prettier vitest="usages:unit" sveltekit-adapter="adapter:static" --no-install --no-download-check
bunx sv add <addon> --cwd apps/web --no-install  # e.g. tailwindcss, eslint, playwright
```

Always re-check the docs linked above before running: flags change.
