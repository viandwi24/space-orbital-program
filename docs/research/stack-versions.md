## Release operations (plan 202, 2026-10-19)

- **Cloudflare Pages `_headers`** (developers.cloudflare.com/pages/configuration/headers, read 2026-10-19): one splat per rule; every matching rule applies and a repeated header is joined with a comma; `! Name` detaches an inherited header; at most 100 rules and 2 000 characters per line. `_redirects` rules apply even where a file exists, so the SPA fallback is a top-level `404.html`, which Pages serves for unknown paths (serving-pages docs); `/x.html` redirects to `/x`.
- **Deploy:** `cloudflare/wrangler-action@v4` with `apiToken`, `accountId`, `command: pages deploy <dir> --project-name=<name>`, and `gitHubToken` for the deployment record (direct-upload CI guide). The token needs Account · Cloudflare Pages · Edit.
- **SvelteKit 3.1.0 client hooks** (svelte.dev/docs/kit/hooks): `src/hooks.client.ts` exports (types from `@sveltejs/kit/hooks` in 3.x) `handleError: HandleClientError` (called for errors during navigation, must not throw, returns `App.Error`) and `init: ClientInit` (runs once at start; async work delays hydration). Neither sees an error outside navigation, so window `error` and `unhandledrejection` listeners are added in `init`.

## Rapier motored joints (plan 288, 2026-10-21)

- **`@dimforge/rapier3d-compat` 0.21.0** (root catalog `^0.21.0`; `RAPIER.version()` 0.21.0). Typings `dist/dynamics/impulse_joint.d.ts`, `multibody_joint.d.ts`, `pipeline/world.d.ts`, read 2026-10-21. Guide https://rapier.rs/docs/user_guides/javascript/joints.
- **Impulse joints** have `configureMotorModel`, `configureMotorPosition`, `configureMotorVelocity`, `configureMotor` and `setLimits`. **Multibody joints** have no motor and no limit setter in the JS build, which `RawMultibodyJointSet` confirms. There is no `maxForce` on either kind. Details in `docs/research/rapier-joints.md`.

Source https://developer.chrome.com/blog/new-in-webgpu-121. three r186: `Pipelines.getForRender(renderObject, promises)` with an array builds via `createRenderPipelineAsync` and `isReady` skips the draw until built; a TSL `Fn` without `setLayout` is inlined at each call. Details in `docs/research/shader-compile-windows.md`.
